## 2. Auditor Defense Guide: Key Interview & Exam Scenarios

### Question: "How does your organization demonstrate compliance with ISO 27001 Control 8.2 regarding Privileged Access Rights?"
**Audit Defense**:
> *"We enforce a strict zero-standing-privilege architecture. All administrative credentials (Windows Local Admin, Linux Sudo, AD Service Accounts, AWS IAM) are held in encrypted HashiCorp Vault safes governed by fine-grained HCL RBAC policies. When engineers need elevated access, they submit a ServiceNow catalog request which triggers manager approval and provisions time-limited membership via Active Directory's PAM Optional Feature (`MemberTimeToLive`), expiring automatically after 2 hours. Furthermore, our PowerShell CPM engine continuously rotates credentials every 30 days and stages passwords before committing changes to prevent lockout."*

### Question: "How do you detect unauthorized privilege escalation or stale access?"
**Audit Defense**:
> *"We execute automated compliance scans via `privileged-access-review.ps1`. The scanner interrogates Active Directory for users with `LastLogonDate` exceeding 90 days (which successfully caught our planted dormant admin `adm_old`), queries Vault metadata to identify secrets unrotated for over 30 days (flagging `svc_backup`), and correlates Windows Event IDs 4728 and 4724 to alert on out-of-band group additions or manual password resets."*
